# Scope game:jam-berulang

Baca AGENTS.md dan docs/architecture/AI-START.md dari root repositori, lalu README.md dan STATUS.md di folder ini. Untuk tugas game:jam-berulang, hanya ubah src/games/jam-berulang/ dan satu change note unik .changes/*.json.
