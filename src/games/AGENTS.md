# Modul game independen

Pilih tepat satu folder ID dan baca AGENTS/README/STATUS di dalamnya. Aturan, console laptop, controller HP, HUD, audio, map, tes, tools dan evidence game harus tinggal di folder itu. Tidak boleh impor game lain/dashboard atau mengedit platform/shared untuk perbaikan lokal. Gunakan manifest dan hook kontrak; tidak ada registrasi pusat manual. Game baru dibuat dengan npm run game:new. Lihat docs/architecture/ADD-GAME.md.
