# Instruksi proyek Main Bareng

- Gunakan Bahasa Indonesia untuk dokumentasi dan laporan pengguna.
- Baca SPEC.md, docs/03-katalog-game.md dan docs/09-roadmap.md sebelum implementasi.
- Portofolio Web-Portfolio-3D hanya referensi visual. Jangan menyalin kode/aset/konten atau membangun ulang game portofolio.
- Fokus dua pemain pasangan, offline LAN, controller browser HP, server otoritatif di laptop. Perubahan cakupan harus dicatat.
- Kerjakan checkpoint beserta verifikasi dan bukti. Jangan mengklaim dokumentasi sebagai aplikasi, uji browser sebagai uji dua HP, atau RTT sebagai input-to-photon.
- Perbarui status dan titik lanjut di docs/09-roadmap.md setelah pekerjaan. Pertahankan hasil pengguna yang sudah ada.
- Jangan mengubah konfigurasi Tailscale, firewall, systemd, atau deployment proyek lain sebagai bagian implementasi rutin ini.
- Secret sesi dan jawaban pribadi tidak boleh masuk log, fixture publik, atau Git. Gunakan data sintetis.
